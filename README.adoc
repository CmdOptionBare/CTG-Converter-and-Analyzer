[[ueberblick]]
== Projektziel & Architektur-Überblick

Handgehaltene Smartphone-Fotos langer CTG-Papierstreifen weisen Schräglagen, Trapez-/Perspektivverzerrungen (_Sägewinkel_), Papierfalten, Abschattungen, gemischte Kamera-Orientierungen (`0°` vs. `90° CCW`) sowie ein hochgradig periodisches `2,5 mm`-Millimetergitter auf. Klassische Panorama-Stitcher scheitern daran, weil sie entweder die Perspektive über 20 Bilder hinweg aufschaukeln oder das periodische grüne Gitter um ganze Kästchen versetzt einrasten lassen.

IMPORTANT: Dieses Projekt löst das Problem durch **metrische Vor-Entzerrung jedes Einzelbildes auf exakt `{canon-scale}` (`1 px = 0,1 mm`) vor dem eigentlichen Stitching** sowie eine **Trennung von Grün-Gitter und Schwarz-Kurve** für eindeutiges, mehrdeutigkeitsfreies Überlappungs-Matching.

[mermaid]
----
flowchart LR
    A["Rohfotos (Ordner / Git LFS)"] --> B["Pipeline 1: Enhance\nFlachfeld + Gitter/Kurve trennen"]
    B --> C["Pipeline 2: Rectify\nProjektiv-Kamm & X-Fächer -> 90° @ 100 px/cm"]
    C --> D["Pipeline 3: Stitch\nMasked FFT NCC + ONNX Patch-RANSAC + DP-Seam"]
    D --> E["Riesiges Panorama\npanorama.png & panorama.webp"]
    D --> F["Pipeline 4: Extract\nGlobales Viterbi-Kurven-Tracking (1 Hz)"]
    F --> G["CTG-Project1 Web-Viewer\nctg_session.json + trace.csv + scans/"]
----

NOTE: Detaillierte mathematische Hintergründe der vier Pipelines und der Web-Anbindung finden sich in xref:docs/architecture.adoc[docs/architecture.adoc].

[[installation]]
== Installation & Schnellstart

[source,bash]
----
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]" # <1>
git lfs pull                      # <2>
----
<1> Installiert `numpy`, `scipy`, `opencv-python-headless` (bewusst headless, um Qt-Konflikte mit `PySide6` auszuschließen), `Pillow`, `PySide6`, `onnxruntime` und `pytest`.
<2> Lädt die 21 realen Testaufnahmen unter `data/inputs/test/2026-11-22_philips_ctg_001/raw/`.

=== CLI-Kommandos (`ctg-tool`)

[source,bash]
----
# Verfügbare Datensätze auflisten
.venv/bin/ctg-tool list

# Komplettpipeline (Enhance -> Rectify -> Stitch -> Viterbi-Extraktion) ausführen
.venv/bin/ctg-tool run-all --split test --dataset-id 2026-11-22_philips_ctg_001

# Neuen beliebigen Bildordner als Datensatz importieren
.venv/bin/ctg-tool import /pfad/zu/fotos --dataset-id aufnahme_02 --split imports

# Kalibrierte 1-Hz-Werte & Scans direkt in CmdOptionBare/CTG-Project1 exportieren
.venv/bin/ctg-tool export-web --target-repo ../CTG-Project1 --session-id 2026-11-22
----

[[visuelle-werkzeuge]]
== Visuelle PySide6-Werkzeuge

Start des Desktop-Studios:

[source,bash]
----
.venv/bin/ctg-tool gui
----

Das Studio arbeitet mit einem gekachelten `1024×1024`-`QGraphicsView`-Canvas (`TiledImageCanvas`), sodass selbst sehr breite Panoramen ohne X11-Pixmap-Limits und bei unter `300 MB` RAM flüssig gezoomt werden können:

1. **Werkzeug 1 — Bildverbesserung & 90°-Kästchen-Ausrichtung**:
   * Umschaltung über menu:Ansichts-Stufe[1. Rohbild | 2. Beleuchtungskorrigiert | 3. Isoliertes Grün-Gitter | 4. Isolierte Schwarz-Kurve | 5. 90°-Entzerrt].
   * Zuschaltbares kanonisches 90°-Kontrollgitter (`1 cm` Hauptlinien, `25 px` = `2,5 mm` Kästchenmaß).
   * Feinregler für Grün-Gitter-Kontrast, Schwarz-Kurven-Kontrast, Schärfung, Zielmaßstab (`px/cm`) und Grob-Orientierung (`Automatisch`, `0°`, `90°`, `180°`, `270°`) mit Direkt-Button btn:[Aktuelles Bild verbessern & 90°-ausrichten].
2. **Werkzeug 2 — Enden zusammenfügen, Kurven-Kontrolle & Export**:
   * Übergangstabelle aller Bildpaare mit `dx`, `dy`, Überlappungsbreite, ONNX-Inliern und Konfidenz-Ampel.
   * **Paar-Deckungskontrolle (Rot/Cyan)** sowie **50/50-Alpha-Überblendung**; bei Bedarf manuelle Feinjustierung in `1 px`-Schritten oder exakt kastenweise über btn:[-1 Kästchen (-25px)] / btn:[+1 Kästchen (+25px)].
   * Direktes Einblenden der extrahierten Kurven (`FHF` rot, mütterlicher `Puls` orange, `Toco` blau) sowie Export über btn:[Als PNG speichern...], btn:[Als WebP speichern...], btn:[Werte extrahieren (CSV + JSON)] und btn:[An CTG-Blatt Web-App senden...].

[[anbindung-ctg-project1]]
== Verbindung mit `CmdOptionBare/CTG-Project1` (CTG BLATT Web-Darstellung)

TIP: Das Schwesterprojekt `CmdOptionBare/CTG-Project1` besitzt eine hervorragende interaktive Web-Darstellung (`src/components/ctg/station.tsx` & `paper.tsx`), nutzte bisher jedoch lediglich grob abgelesene Stützstellen (`reading.json`). Unsere Pipeline 4 (`extract.py`) liefert nun exakt die fehlende deterministische **Bild-zu-Wert-Pipeline** (`0,1 mm` / `0,2 bpm` Rasterauflösung).

Mit einem einzigen Befehl werden `src/data/ctg/<id>.json` (`CtgSession`-Schema), `public/ctg/<id>/trace.csv`, `events.csv`, `panorama.webp` sowie passgenau auf `paper.tsx` zugeschnittene `scans/*.jpg` inklusive exakter Sekundengrenzen `[t~0~, t~1~]` aus dem Panorama-Stitching übergeben:

[source,bash]
----
.venv/bin/ctg-tool export-web --target-repo /pfad/zu/CTG-Project1 --session-id 2026-11-22
----
